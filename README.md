# Projeto Printscreen - Sistemas Distríbuidos

### Objetivo Geral

Enviar ao servidor a área de transferência de imagens do cliente (printscreen de imagens) e alterar a área de transferência de texto do servidor.

### Funcionalidades

* **Captura de Printscreen:** Lê automaticamente a última imagem copiada para a área de transferência do cliente.
* **Comunicação via Sockets TCP:** Transmissão segura e estruturada de bytes entre máquinas distintas pela rede.
* **Compatibilidade Multiplataforma:** Suporte para comunicação entre diferentes Sistemas Operacionais.
* **Persistência e Injeção de Texto:** O servidor armazena a imagem recebida em disco e atualiza o seu próprio clipboard local com uma string de confirmação.
